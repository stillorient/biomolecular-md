# 从选定模型到可执行协议

在体系/模型确认后，或用户明确授权非运行演练时使用；演练的 A/B 均保持未确认。历史审查只核对实际发生的工作，不补造确认或参数记录。资料编号见 [证据索引](evidence.md)。以下是设计规则，不是预设参数。

## 1. 把科学选择落实到实现

| 环节 | 卡片和执行文件中必须确定的内容 | 验证方法 | 失败或不适用时的处理 |
|---|---|---|---|
| 输入与结构准备 | 原文件/序列哈希、组装体与原子映射、缺失区处理、每个移除/替换/新增组分及依据 | 对照构建体核查链/残基/原子、手性、共价键、几何冲突；保留修复前后差异 | 不以删除报错残基或清空缺失区列表代替处理；回到模型评估 |
| 质子化/端基/连接 | 位点微观状态、端基电荷、二硫键/环化/修饰、关键 His；来源和歧义 | 残基模板与实际成键、局部氢键、净电荷/价态检查 | 参数覆盖或关键状态不明则阻止依赖它的运行 |
| 参数和软件 | 每种组分与连接的参数文件、发行版本/哈希、引擎/插件/转换版本 | 全体系参数分配；检查排除项、1–4、组合规则和特殊非键项；必要时代表构型能量/力对照 | 定位缺项/转换损失；不得静默用通用参数替代 |
| 溶剂/盒/离子 | 溶剂与水文件、几何、盒向量/建盒规则、padding、离子种类/参数、盐定义和中和方式 | 额外粒子、周期性自接触、实际离子数/电荷、溶剂密度与盒尺寸；溶质运动范围的余量 | 盒过小或离子/水不匹配时重建；区分中和反离子与添加盐，不把有限盒浓度当精确宏观值 |
| 膜等特殊环境 | 脂质组分/比例、取向、周期边界、压力/表面张力方案 | 组成、膜厚/面积、周期性、体系特有稳定指标 | 不沿用溶液各向同性压力设置；必要时查专门建系与平衡依据 |
| 非键相互作用 | 静电方法、截断/邻居表、PME 参数或误差容限、LJ 切换/截断、长程色散及适用修正 | 与该模型和引擎文档一致；最终解析值/日志核对，必要时精度敏感性 | 不把一个力场的 cutoff/switching 原封不动移到另一个；修正冲突后更新 B |
| 积分与约束 | 积分器、dt、约束对象/算法/容差、刚性水、质量重分配 HMR、虚拟位点、COM 去除 | 实际 System/topology/config 检查；约束警告、漂移或步长敏感性；用时间工具核对 | HMR/约束不是自动允许大步长的证明；失败时按计划回退或更新 B，动力学结论另核实 |
| 恒温/恒压 | 算法、目标值、耦合参数/单位、耦合组、是否各向异性、barostat 频率/时间常数 | 核对目标系综和引擎语义；统计窗口的温度/密度/体积等 | 不把 MC barostat 的步数频率当耦合时间；不要求瞬时压力每点接近目标 |
| 约束释放 | 原子选择/实际原子数、参考坐标、位置约束函数/k/单位、每阶段变化 | 选择与预期相符；参考和 PBC 一致；释放后的目标量表现 | 不让约束把待研究的界面稳定性强行固定；若生产保留约束，明确结论受限 |
| 输出与可恢复性 | 各阶段状态/轨迹/检查点间隔、时间与单位、精度、写入方式/阶段标记 | 输出点数足以判定窗口；短恢复检查、原子顺序与时间连续性 | 有 checkpoint 不代表能恢复；在生产前解决读取/重复帧/覆盖风险 |

建系用的几何模板与最终物理水模型应分开记录。例如使用其他四点水的种子坐标放置溶剂时，最终必须核对所选水的真实约束几何、虚拟位点权重和专用水/离子参数；不能因粒子数相同就当成同一模型。检查加氢等中间拓扑是否已具备最终力场要求的额外粒子，避免把缺虚拟位点的临时 System 当完整模型。

引擎说明：[E05–E07]。例如 GROMACS 官方不建议新模拟使用 Berendsen barostat；选择正确系综的方法并依据远离/接近平衡的状态设计参数。OpenMM 常见的 MC barostat 和其他引擎的压力耦合参数含义不同，不能只转抄数值。准备工具的内部计算也必须属于获准范围，见 [非运行核查](nonexecuting-checks.md)。

## 2. 阶段、验收与资源边界

根据体系选择阶段；无需为“齐全”机械地执行所有阶段。所有实际积分阶段都写 **dt、步数、总时长、输出间隔、最大预算**；最小化写算法/容差/单位/最大迭代次数，不编造 MD 时间。

| 阶段 | 必须设计的判断 | 不通过时 |
|---|---|---|
| 建系静态核查 | 组件/电荷/连接/参数覆盖；单点能量/力若获准执行，检查非有限值与明显异常分量 | 未确定化学模型前不运行最小化“试试看” |
| 最小化 | 指定收敛标准、最大迭代、约束与需要消除的冲突；能量有限不是充分的几何验收 | 查输入、约束和参数；达到迭代上限不能直接标记收敛 |
| 加热/初始松弛（若需要） | 初速度来源/温度与随机种子；温度调度、约束及初始构象风险 | 保存日志；按已确认的有界策略重试，不任意升温或加强约束 |
| NVT/NPT 或其他适用平衡 | 每阶段必要性、最短/最长长度、观测窗口、约束释放；温度/能量/体积/密度和相关结构指标 | 先判断未平衡、设置错误还是物理变化；允许的延长须预先写明上限 |
| 试运行与恢复验证 | 数值稳定、足够密集诊断、输出正确、约束/配位/构象异常排查、恢复连续性、实际速度 | 只能证明这些有限检查；按问题修正或暂停，不能将通过写成力场已验证 |
| 生产与独立重复 | 每重复初始状态/种子、目标长度及总上限、分析目标、是否条件自动继续 | 依误差、慢过程和跨重复差异决定延长/加重复/换方法；达到上限仍不足则报告不足 |

验收标准在看生产结果前确定：写明 **观测量、单位、窗口/采样频率、计算方法、容许范围或误差准则、依据、失败动作**。数值阈值必须有适用依据；没有依据时标待评估，仅允许相应范围的探索性计划。不能事后为某一结果改门槛。

静态检查验收窗口确实容纳于对应阶段，输出间隔能提供所需数据；例如比较两段窗口不能只安排一段窗口长度的平衡。更改阶段时长、输出间隔或续跑相位后同步复核这些条件。

平衡/收敛不能由统一 RMSD 或固定时长宣布。若使用自动平衡检测，它针对选定观测量，不能证明未观测慢状态已采样。[E01–E03] 不将纯水密度、球状蛋白尺寸或固定 RMSD 范围套到混合溶剂、膜或无序体系。

独立重复要考虑不确定性来源：不同速度/随机种子支持采样重复，不能独立覆盖共同起始 pose 的偏差；需要时另列不同合理构象或微观状态。Communications Biology 清单的至少三次重复可作有出处的设计起点；本项目的数量与长度仍由目标精度、慢过程和预算解释，单次探索不冒充稳健统计。[E01, E20]

预算至少列每条件重复数、总积分步数/模拟时间、允许的试错与延长、CPU/GPU 数/并发、墙钟或费用硬上限、存储和 checkpoint 周期。未实测吞吐量时给估算范围，先在批准的试运行上限内测量；更新预计耗时不等于获准超出预算。

## 3. 时间与配置一致性

验证入口应重新检查当前配置和参数，或显式验证缓存证据对应的全部输入/实现指纹；仅读取旧的 PASS 报告不能代表当前文件通过。逐项标记配置承诺的输出及其写出/读取实现，未实现的产物与调度、分析、恢复功能列为执行前缺口，不把设计路径当成已经可调用的功能。

涉及具体执行代码时按 [执行实现合同](execution-contract.md) 核对逐原子身份、实际盐/水计数、真实确认绑定、独立进程硬限和不可变输出；用参数变更、合成轨迹、受控中断验证行为。工程合同通过仍不替代实际建系和科学适用域验收。

每个恒定步长阶段满足 `duration_ns = steps × dt_fs / 1,000,000`。报告间隔同样换算。步长变化必须拆段或记录真实累计时间；不能用计划总长除帧数重建截断/拼接轨迹的时间。

用 [check_timing.py](../scripts/check_timing.py) 核对实际计划值：

```text
python <skill目录>/scripts/check_timing.py --dt-fs <实际步长> --steps <实际步数> --expected-ns <卡片时长> --interval-steps <输出间隔>
```

对各阶段、不同输出间隔分别调用；不整除时工具给出余数，明确最终帧是否另存。工具的输出数量按该段从 step 0 开始且定期输出计算；阶段继承或续跑需另核对全局 step 对 reporter 周期的偏移。示例占位符不是命令默认值。这个工具不读取执行脚本，也不评估步长物理正确性，因此还必须核对引擎最终配置。

恢复时区分“本段新增步数”和“全程目标步数”，不得重新执行完整生产步数。保留阶段编号、全局 step/time、续跑历史及去重规则。不要为恢复生产无意重置速度、种子或重新平衡。

## 4. 分析与可支持的结论

按问题选择指标，不自动堆满图表。所有指标记录原子选择、单位、参考结构、帧窗口、平衡剔除、统计方法和解释边界。

| 任务 | 实现/验证重点 | 解释限制 |
|---|---|---|
| 通用轨迹读入与 PBC | 拓扑和轨迹原子顺序一致，真实 step/time 与完整盒矩阵；可信键图 make-whole/unwrap，区分居中和 wrap | 只做链质心平移不能修复断开的分子；三斜盒不能用正交盒长度公式代替 |
| 蛋白/伙伴构象与位姿 | 分别记录受体对齐后的伙伴运动、伙伴自身拟合后的内部变化；参考初始/实验/聚类结构的目的明确 | 全复合物 RMSD 可能掩盖界面；靶标对齐后的伙伴 RMSD 混有平移和转动 |
| 接触、氢键、盐桥、界面面积 | 预定义距离/角度阈值、原子选择及占有率统计；初始与新增接触分开 | 周期距离使用与盒一致的坐标；拟合旋转后的副本不能搭配未旋转盒直接求 PBC 距离 |
| 状态、聚类与代表帧 | 使用预定特征/距离和统计窗口；报告簇占比和跨重复表现 | 代表帧由簇与占比选择，不能挑一张最好看的帧代表全部结果 |
| 误差与对比 | 针对主要量检查自相关、有效样本/块长度、跨重复差异及效应量/区间；层级与重采样方法清楚 | 相邻帧不独立；有效样本不足/状态无转变时不能报虚假的窄误差；统计误差不涵盖所有模型误差 |
| 实验比较 | 相同构建体/条件与可反算量，前向模型、实验及采样不确定性 | 用于选型/调参的数据不再算独立验证；没有实验时明确外推边界 |

PBC 依据 [E17]；统计与实验依据 [E02–E04]。

MM/PBSA/GBSA 仅在问题确实需要且有匹配基准时作为独立方法分支：明确参数/介电、溶剂化、熵处理、取帧和统计；不同条件的端点分数不能自动成为 Kd/IC50。蛋白–肽和 PPI 基准分别核实，不照搬小分子性能或旧短轨迹协议。[E18]

严格自由能/增强采样另写适用的采样、修正、重加权和误差方案；本参考不是这些方法的实施手册。[E19] 普通受约束轨迹不能直接解释为无约束系综；有偏轨迹不能未经处理计算无偏占比或动力学。

## 5. 可复现归档与旧结果审查

保存原始/准备后结构与序列、链/原子映射、拓扑、参数文件及 SHA256、引擎/插件/分析环境、脚本与解析配置、卡版本及用户确认、实际随机种子/初始状态、轨迹/盒/日志、失败/续跑历史、检查点和适用的可移植状态。检查点可能依赖平台/版本；便携状态也不保证逐位相同的随机轨迹。[E05]

运行记录与已确认快照分开，防止补写记录改变批准内容。报告每一项实际偏离以及影响。历史轨迹若映射和时间可信，窗口/PBC/误差处理问题可先重分析；模型化学错误可能需要重建；采样不足可能需要补采样。不读取真实产物就不得凭旧脚本推断过去全部模拟有误。
