# 体系与模型适配

本文是依据 [证据索引](evidence.md) 综合制定的决策规则，不是一套文献宣称通用有效的参数表。先判断方法可回答什么，再判断组件有没有参数，最后判断这些参数对目标量有多大证据支持。

## 1. 输入事实与目标

| 需要确定的事实 | 如何核实 | 不明确时的处理 |
|---|---|---|
| 研究问题、条件、主要观测量、所需精度 | 与实验/筛选目的对应：局部稳定、构象分布、界面差异、自由能、动力学或反应 | 先给可支持的结论范围；不能用结构保持替代结合强度或反应问题 |
| 实际序列、构建体、组装体与全部链 | 对照原始序列、PDB/mmCIF 组装信息、实验构建体、链身份；结合entity/组分类型、auth编号/插码映射，水或离子可能复用聚合物auth链ID；同源链/对称性显式映射 | 不按最长/最短链自动只留两条；列出影响界面的组装体歧义 |
| 结构可靠性、缺失区/重原子、断链与替代构象 | 实验质量/局部支持、完整序列对齐和逐原子覆盖；检查NMR是单个平均结构还是多模型ensemble；预测模型检查界面/局部不确定性及合理替代构象 | 残基存在不等于原子完整；修复、删减或封端都记录新原子与模型变更；建模坐标不是实验事实 |
| 端基、二硫键、环化、D/L、非标准残基 | 原始连接记录、化学构建体、手性和成键检查；区分序列截断与真实游离端 | 不自动替换成标准 L 型或开放链；关键连接未知时停止依赖它的准备 |
| 糖基、脂质、金属、辅因子、配体与结构水 | 逐组分列保留/移除及功能依据；金属明确氧化态和配位 | “没写在普通蛋白 ATOM 中”不等于杂质；缺必要参数时保留并转参数化评估 |
| pH、温度、盐、溶剂/膜和压力环境 | 使用实验条件或明确的建模假设；记录浓度定义与离子种类 | 未提供条件先提出有依据的候选供确认，不能悄设“生理条件” |
| 关键质子化/互变异构状态 | 位点环境、pKa/实验依据、His 等局部氢键网络；区分配体和蛋白 | 不确定且会改变结论时比较合理微观状态或选择适用的恒 pH 方法 |

输入 pH 给加氢工具不等于模拟了动态滴定。保留原文件与逐原子/残基映射；清洗输出后的丢失信息不能靠猜测恢复。[E06, E07, E15]

## 2. 候选选择的证据结构

评估完整组合：蛋白/肽参数 + 水 + 离子 + 糖/脂质/辅因子/非标准残基 + 共价连接与补丁 + 非键约定 + 软件实现。不能只填“AMBER”或“CHARMM”。

对有实际价值的每个候选，回答：

1. 参数覆盖实际化学实体、连接与手性吗？原子类型分配成功只是必要条件。
2. 验证体系在构象类别、相互作用、环境、目标观测量上与本体系多近？
3. 依据属于原始开发验证、独立基准、官方实现支持，还是本项目外推？文献“用过”弱于相关观测量上的验证。开发拟合数据与独立验证分开；同论文的不同网页不算独立证据。
   同时找与关键化学特征和目标量相关的反证/失败基准，不能只收集支持使用的论文。已知热力学偏差不能由短时结构保持或参数覆盖消除；例如 CaM 的 Ca²⁺ 结合问题已有 C36m/Drude 的直接基准警示。[E24]
4. 参数/软件版本可获得且可追溯吗？移植是否保持特殊项、混合规则和排除项？
5. 哪个风险会改变主要结论？用什么观测量、实验、替代状态或模型能检验？证据不够时如何限定用途？

可以只保留一个有成熟依据的组合，不强迫双力场。需要替代时，选择能检验具体不确定性的模型，而非穷举。不同力场比较要遵守各自数值约定；不能为“参数一致”而破坏模型。来源 [E04, E05, E08–E12] 支持这些判断，但没有自动选出新体系最优力场的算法。

## 3. 特征触发的适配分支

多个特征可同时触发；需要满足它们的交集，不只按“蛋白–肽”一个标签选型。

| 触发特征 | 可考虑的处理与依据 | 验证 | 不适用/不通过时 |
|---|---|---|---|
| 标准水溶性折叠蛋白、普通线性肽 | ff19SB + OPC、CHARMM36m + 匹配的 CHARMM 水/离子可进入候选；确认构建体与端基。[E08, E09] | 目标结构/界面指标、相关实验与模型适用域；柔性伙伴另看下行 | 不因候选常见就放行；排除未覆盖的化学状态，补针对性验证 |
| 柔性短肽、IDR、结合伴随折叠 | 关注未结合态尺寸/二级结构与蛋白–水平衡；评估 CHARMM36m、a99SB-disp 等的相关基准及精确配套溶剂。[E09, E10] | 合适的 NMR/SAXS 等反算、状态分布、采样和前向模型误差 | 不能把 a99SB-disp 配套水换成任意 TIP4P-D；证据不匹配时标为外推，改变模型或采样设计 |
| 弱缔合、带电界面、聚集/结合能为核心 | 寻找蛋白相互作用基准，检查盐与质子化；单链验证不能替代 PPI 验证。[E11] | 缔合/界面相关观测量、合理浓度与有限尺寸、模型/状态敏感性 | 不按“最不解离/最黏”挑力场；区分模型偏差和未采样，无法分清则保留不确定 |
| 环肽、D 残基、N-甲基或其他骨架改造 | 显式闭环/端基/手性/扭转和顺反异构；寻找化学相符的验证。[E12] | 参数覆盖、环几何与二面角分布、相关实验和异构采样 | 不能把通用小分子自动参数化当验证；转参数开发/基准或停止该模型 |
| 糖、脂质、膜、辅因子或小分子共存 | 查相容的组件、连接补丁和构建工具；膜类型/张力条件影响压力耦合。[E05, E06, E14] | 成键/电荷/原子映射、参数兼容；膜面积/厚度/取向等实际指标 | 不静默删除难处理组件；构建工具支持不代表该组合科学准确，必要时专门参数化 |
| 金属中心 | 确认氧化态、配位及是否研究配位变化；有键/非键/极化/QM/MM 路线依问题决定。[E16] | 几何、局部电荷与适用参考数据；有键模型不能检验被固定的配位变化 | 金属化学身份未知时停止参数分配；反应或配位变化不能用固定拓扑结论代替 |
| pH 依赖、埋藏电荷或关键 His | 固定微观状态需依据；必要时有界的状态敏感性或受支持的恒 pH 协议。[E06, E15] | 位点/微观状态、pKa 相关证据；恒 pH 特有采样与实现检查 | 缺少方法支持时报告限制；不能只传一个 pH 数字后声称捕捉滴定 |
| 慢过程、稀有事件、严格自由能或动力学 | 先评估常规 MD 的时间尺度与目标；若需要增强采样/自由能，另写有文献与实现依据的完整子协议。[E02, E19] | CV/窗口或状态覆盖、重加权/重叠、误差、标准态/约束修正等适用检查 | 不自动套 metadynamics；偏置轨迹的时间不是通常物理动力学时间，无法验证则限定问题 |

粗粒化和反应性研究需重新确定分辨率、参数适用域与可支持观测量，不能沿用上表的全原子参数。专门方法本 skill 负责判断和路由，不预装一套未经验证的万能脚本。

## 4. 组件与实现的易错点

- OpenMM 官方支持 `amber19-all.xml` + `amber19/tip3pfb.xml`；原始 ff19SB + OPC 也是有依据的候选。不能因为后者在原论文中使用就判前者非法；它们是不同组合，适用证据分别判断。[E05, E08]
- CHARMM 修订 TIP3P 与普通 TIP3P 不等同。蛋白、配套水和离子文件必须核对同一发行版本；当前文档示例名称可能随安装版本变化，不直接硬编码为执行参数。[E05]
- 核实具体蛋白版本，而非仅看家族名：OpenMM 的旧 `charmm36.xml` 不含 CHARMM36m 蛋白参数，不能与包含 m 参数的 `charmm36_2024.xml` 互换后仍声称同一模型。[E05]
- 四点水的额外粒子/虚拟位点、几何和离子兼容性需要建系验证。特定模型的配套水不应被同名/近似模型替换。[E06, E10]
- 不混用来源不明的原子电荷、1–4 缩放、组合规则、NBFIX/特殊成对项或端基模板。跨引擎转换核对参数映射，并对代表构型比较同一物理定义下的能量/力；报告可解释的约定差别。
- 预测结构与实验结构都需局部检查；“MD 后更稳定”不验证预测复合物 pose。新连接、缺失环或关键初始界面不确定时考虑合理替代构型。

## 5. 用证据形成决定

“可制定生产计划”需有明确化学模型、适用域依据、可实现的参数组合及验证策略；不是已经证明正确。“仅可制定探索性验证计划”适用于参数覆盖明确但准确性/采样证据有限，范围与结论必须受限。“暂不适用”适用于关键化学事实未知、必要参数不支持或方法无法回答主要问题。

预先定义能改变决定的观测量和精度。实验比较需考虑实验条件、反算模型、系统误差与采样误差；用来挑模型的数据不能再冒充独立验证。[E04] 没有直接实验时可以做有边界的探索，但不能声称已验证特定体系的准确性。

两套合理模型不一致时先检查初始状态与采样；只有采样证据足够才讨论模型差异。两套模型一致也可能共享偏差。记录“不适用”的具体理由、缺失证据和最小补救方案，不用无来源的统一 RMSD、时长或重复数阈值掩盖不确定性。
