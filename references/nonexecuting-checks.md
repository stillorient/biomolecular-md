# 非运行演练与静态核查边界

用户只要求方案/演练或禁止最小化/MD 时使用。可以生成具体 A/B 草案、配置与代码；所有测试选择标为项目假设，确认记录仍未批准。不要为了走完流程编造确认，也不要在明确的非执行授权下仅停在空模板。

## 准备工具可能包含计算

核对实际版本源码/调用链，而非凭 API 名称判断。已核查实例：

| 版本与方法 | 实际行为 | 禁止最小化/积分时 |
|---|---|---|
| OpenMM 8.4.0 `Modeller.addHydrogens` | 创建 Context 并调用 `LocalEnergyMinimizer.minimize` | 不调用；可以静态检查缺 H、微观状态和模板，实际加氢留待授权阶段 |
| PDBFixer 1.12 `addMissingAtoms` | 新建原子时可最小化，并在碰撞处理中最多循环10次 `integrator.step(200)`；默认最小化调用未给迭代上限 | 只做缺失检测/方案与文件生成，不执行该修复入口；未来授权时明确内部计算和资源上限 |
| PDBFixer 1.12 `addMissingHydrogens` | 委托给 OpenMM 加氢方法 | 同上 |
| OpenMM 8.4.0 `Modeller.addMembrane` | 最小化并短积分调整膜 | 建膜也不是自动纯静态操作 |
| OpenMM 8.4.0 `addExtraParticles`、`addSolvent` | 已读版本的方法本身未见最小化/积分；仍会改模型，参数生成器可有额外副作用 | 根据本次允许范围决定是否调用，不能把这条观察外推到所有版本/插件 |

源码见 [E22/E23](evidence.md)。本表不是所有工具的安全列表；对未知或调用外部参数生成器的方法继续核对。严禁为“验证没运行”而先试一次会运行的 API。

可做：原始结构/序列和组装体核对，几何与成键分析，XML/拓扑/化学图和单位检查，在可信、无外部计算生成器的参数集上构建无坐标的 System，对配置和阶段时长进行静态解析。未创建 Context、未求能量/力、未最小化、未积分的模板化学图编译可以验证参数覆盖，**不等于已生成可运行坐标或完成真实溶剂化**。保留原始结构中缺原子/端段与建模新增原子的映射，不能用模板节点冒充实验坐标。

## 分开报告五种状态

1. **计划具体性**：该阶段的模型/数值/实现/单位/预算/门槛是否明确；可在不运行时完成。
2. **静态覆盖**：实际选用的组分、连接与状态是否有参数，是否已验证化学图编译。若仅有 XML 名称/文件存在就如实标“未编译”。
3. **坐标建系与数值验收**：真实准备产物、原子顺序、几何/盒/离子数、输出和后续数值表现。未进行的保持未进行。
4. **科学适用域**：支持、反证、外推、可支持的问题。工程编译通过不能覆盖模型反证；改为受限探索必须明确改变目标与结论。
5. **用户授权**：只接受真实用户对具体范围的确认，其他四项都不能代替它。

计划可以具体且尚未获准运行；科学目标也可以受阻而仍有完整、明确禁止推进的验证计划。不能以填满两张卡为通过标准。

## 阶段输出与确定生成规则

实际准备后才出现的溶剂数、盐离子数、坐标/拓扑哈希和验收值，B 中写明生成规则、随机性/来源、输出位置、阶段后核对方法及失败动作；不填伪数值。批准可限定为有边界的准备/试验阶段，生产等其验收后按原授权范围推进。必要化学身份、模型文件或连接参数缺失，则不能用这个机制推迟关键科学选择。

锁定并核对物理模型身份。库加载失败时优先诊断资源/转换/支持，不要换到能加载的同族旧文件后仍用原模型名称。例：OpenMM 的 `charmm36.xml` 不含 CHARMM36m 蛋白参数，`charmm36_2024.xml` 包含；水文件也须同版。[E05] 合理改换模型必须更新依据和 A/B，而不是消除报错的隐式回退。
