# 执行实现、身份追踪与恢复的核查合同

在编写/审查执行代码时读取。本参考约束“代码是否兑现 B 卡”，不规定某套力场、引擎、时长或统计阈值；专门方法需要自己的适配器。实际引擎 API 语义以锁定版本源码/官方文档为准。

## 1. 输出必须有写出者、读入者和证据类别

把 B 卡的每项承诺对应到配置字段、执行函数、最终解析值、产物和验收。仅能解析 JSON、找到文件名或编译模板，不表示该功能已实现。未知的可执行字段/未支持方法应明确拒绝，避免静默忽略。

逐原子追踪贯穿原始结构、构建体裁剪/封端、缺失重原子、微观状态/H、溶剂/离子/虚拟位点和最终 topology/System 顺序。原始身份包括输入哈希、model/chain/residue/insertion code、atom/altloc；新增原子记录来源与父原子/组分，删除记录理由。重排索引不能改变身份；原始水、建模 cap 和天然残基不得只按相同编号混同。离子替水可追踪到被替换的水氧，但“盐离子/中和离子”仅是相同物理离子的计数分类。

最终电荷/质量/虚拟位点/连接从真实 System 提取，与拓扑和坐标逐项核对。保存机器可读拓扑及坐标，不能依靠可能改名、舍入或丢失虚拟粒子的 PDB 回读恢复内部顺序。PDB 可作为可视化副本。

计数报告分三层：目标值、根据已记录输入/算法推导的值、实际生成后观测值。给出保留/新增/替换水、盐对、中和离子、总离子、虚拟粒子、净电荷、盒矩阵/体积和浓度分母。以 OpenMM 8.4.0 为例，`_addIons` 的水代理公式使用新加入的可替换水，不包括保留晶体水；不能用最终水总数反推相同盐对数。调用私有实现须锁定并验证源码，不能跨版本沿用。总盒体积浓度、可达溶剂体积浓度、水代理浓度不是同一个量。

存储也须适配：计算块、状态/轨迹输出、checkpoint、提交和保留是不同周期，分别核查实际消费。固定 System/Integrator 应引用或每阶段只存一次；不能每个短计算块重复完整 XML/状态，令计划必然超预算。静态容量估算覆盖全部条件/重复、允许延长、粒子选择/精度、日志、分析、元数据和替换时的临时峰值；真实准备数量已知后再预检。仅计本次 run 的明确范围，不把共享 runtime、他案或历史测试算入。若采用滚动 checkpoint，B 明确保留数量、先提交新可恢复代再退休旧载荷的顺序、损坏/中断处理和永久保留的科学数据；不能静默删轨迹或扩大预算。省略可重建虚拟位点时保存所选列顺序及精确重建参数，不能把轨迹当作完整粒子数组读回。

真实准备产物、合成测试夹具和纯模板图分别标记；合成水数或坐标不得进入“实际准备已完成”的报告。

## 2. 确认和硬预算必须由执行入口兑现

沿用真实有效确认；记录原话/消息定位、时间、A/B 版本/哈希、阶段范围及资源上限。冻结输入、卡、配置、实现代码、参数和运行环境身份。运行前及子进程入口核对绑定；一个 `authorized=true` 布尔值不能证明用户同意。文件格式校验也不能独立证明记录来自人类，仍须有会话/运行器的可信确认来源。合成授权只允许假执行器。

准备 API 的内部最小化/积分也计入获准阶段和预算。在会独占/长时间阻塞的引擎调用之外，以独立进程监督墙钟、全局资源和存储上限；仅在 worker 内设置 timer 不构成可靠硬限。记录已消耗预算，重启不清零。并发/设备数量必须进入计费；没有资源预留证据时，不把预算计算冒充实际 GPU 用量。

先尝试有时限的协作保存，硬截止时终止并回收子进程；明确不能保证强杀时产生最新 checkpoint。写入文件关闭后再原子提交同一代的检查点、状态、轨迹与日志哈希。未提交/残缺代不可接入分析或续跑；旧提交不可覆盖。监督进程自身异常退出留下锁/未结算预算时，先核实孤儿任务已停止并对账，不能自动再启动一份。

最小化达到最大迭代或函数返回均不是充分收敛证据。受约束最小化的目标梯度、约束误差与未经投影的物理力不同；按锁定引擎的实际语义记录收敛/停止原因。若 API 无法提供足够诊断，保守标为未验证并停止，不能偷换为原始力阈值。外层墙钟仍须覆盖约束修正可能超出 nominal iteration 的情况。

## 3. 阶段参数和续跑语义

执行配置应真正控制温度/压力、积分器、约束、非键项、COM、位置约束原子/参考/k、种子、长度、输出和验收。用构造器 getter/实际日志检查数值；改变字段应改变对应对象/行为，或得到明确“不支持”，不能只证明 JSON 文本改变。

不可省略的有限性、完整数据、实际 step/time 连续性和约束失败检查独立于可选门槛列表；空列表、无样本或已知失败不能因 `all([])` 成为通过。对影响执行的字段校验类型、有限数、范围和整数步数；布尔值不是合法步数，NaN/Infinity 不是合法容差。假引擎/State 应走生产使用的同一调度与恢复实现，覆盖不相同周期、检查点间中断和协作保存，避免另写简化循环后只测简化版本。

区分两种恢复：

- **同一阶段 checkpoint**：核对 System、Integrator、引擎/build、平台/精度、设备/驱动及输出身份，恢复内部状态和 RNG；只执行 `目标总步数 − 已完成步数`。不重设速度/种子，不回退到便携 State 假装同样随机轨迹。
- **切换阶段 State**：显式继承坐标、速度、盒、实际全局 step/time；新阶段应用自己的约束、热压参数和随机种子。不要盲目恢复旧全局参数覆盖新阶段设置。便携 State 不含 checkpoint 的完整 RNG；不能声称逐位连续随机轨迹。只有计划指定的初始阶段生成初速度。

保留阶段内进度与全局 step/time，检查时间与实际 dt 一致。输出使用真实时间和完整盒；按阶段内或全局步数报告都可，但相位必须明确、可检查。允许延长的阶段、次数/增量、触发条件和预算在确认范围中预先确定；失败不自动进入下一阶段，生产不得依“跑完”替代验收。

重复/恢复的相同帧只有坐标、盒、step/time 全部一致才能去重；冲突重复应拒绝。缺口、崩溃及最后一段未提交数据要报告，不能用计划时间插值填补。

## 4. 分析实现的行为验证

检查受体/伙伴角色、原子身份、实验参考与新增原子排除、可信键图连通性。用跨边界构象测试 make-whole、正交/支持的三斜盒最小镜像。受体拟合下伙伴位姿与伙伴自身拟合的内部 RMSD 分开；距离/角度使用原坐标与匹配盒，不能与旋转后的拟合副本混用。

按卡实际计算主要接触、氢键角度、盐桥、水桥、构象/聚类等所需指标，保存原子/残基选择和阈值。原始水身份跟踪能回答初始水的去留；水桥占有率不能只追一颗初始水而忽略水交换。初始接触分数只是一个观测量，不能自动代替所有科学目标。

带电基团依已确认化学与拓扑选择。例如去质子化游离 C 端的两个羧酸氧都属于负电荷组，不能只选名为 OXT 的一个氧，也不能把所有内部肽键羰基 O 算成负电基团。分析入口先核对映射/准备清单/参考输入的哈希与绑定、条件/重复、逐原子索引及轨迹列顺序标记；相同粒子数不保证相同身份。拒绝改标签、错重复、改参考或换顺序，即使轨迹为空也先拒绝来源冲突。合成来源同样显式标记、绑定，不能借测试身份字段省略追踪。

统计使用实际生产起点和时间、预先剔除段、自相关/ESS、足够长的相关块与独立重复层级。常数序列、无相关转变、窗口不足、重复不足或漂移时报告不足；不能凭极窄区间或低 RMSD 通过科学验收。报告各重复/条件、描述性效应和区间的统计含义，不把边缘区间当成配对差异区间。

无 MD 授权时可测试：真实输入的纯文件/化学图，参数构造器，已知几何的合成轨迹，带明确合成标签的假执行器、短暂普通子进程超时/崩溃和假 checkpoint。测试必须覆盖行为和失败恢复，而非标题/关键词或格式快照。此类通过只证明这些实现性质；真实准备、引擎 checkpoint、GPU 性能和科学采样均仍待获准后验证。
